# ZipGallery

**English** | [简体中文](README.zh-CN.md)

**Browse images inside ZIP / CBZ archives, and handle everyday compression and extraction.**

ZipGallery is a macOS archive utility. Read image collections without extracting the entire archive, or switch to a file list to inspect and extract ordinary files. The app bundles 7zz, so you do not need to install 7-Zip separately.

[Download the latest release](https://github.com/DuckFeather10086/ZipGallery/releases/latest) · [Quick start](#quick-start) · [Development guide (中文)](docs/DEVELOPMENT.md) · [MIT License](LICENSE)

## Features

- **Images inside archives:** preview JPEG, PNG and WebP files in unencrypted ZIP / CBZ archives, with natural sorting, thumbnails, folder navigation and a full-image viewer.
- **Continuous paging:** scroll or hold an arrow key to turn pages. When zoomed in, scrolling moves around the image instead.
- **Reading history:** remember the last 20 archives and reading progress. Go back and forward through folders and archives opened during the current session, restoring selection and scroll position.
- **Compression and extraction:** create ZIP, 7z and tar.gz archives; list and extract formats supported by 7zz, including RAR. RAR creation is not supported.
- **Passwords and job controls:** set a password when creating ZIP / 7z archives, unlock encrypted archives before browsing and reuse the verified password for extraction, track progress and cancel jobs. Outputs require a new name and never overwrite existing content.
- **Mounted SMB shares:** open archives from shares already connected in macOS, and save compression or extraction results to them.
- **Filename encoding repair:** preview legacy ZIP / CBZ filenames and save a UTF-8 copy while preserving the original archive.
- **Finder integration:** application and archive icons, drag-and-drop opening, and Finder “Open With” associations.

## Download and install

Current releases are for **macOS Apple Silicon (arm64, M-series chips)**. The app has been tested on macOS 27.0.1. Intel Mac, Windows and Linux builds are not available, and compatibility with older macOS versions has not been fully tested.

1. Open the [latest release](https://github.com/DuckFeather10086/ZipGallery/releases/latest).
2. Under **Assets**, download `ZipGallery-VERSION-macos-arm64.dmg`. GitHub's automatically generated `Source code` downloads are not installers.
3. Open the DMG, drag `ZipGallery.app` into **Applications**, then launch it from Applications.
4. Alternatively, download `ZipGallery-VERSION-macos-arm64.app.zip`, unzip it, and move the app into Applications. Choose either installation method.

**First launch:** releases are ad-hoc signed and do not yet have Apple Developer ID signing or notarization. If macOS cannot verify the developer, first confirm that the download came from this repository's Releases page. If you trust the source, follow [Apple's instructions](https://support.apple.com/en-us/102445): after attempting to launch the app, go to **System Settings → Privacy & Security** and choose **Open Anyway** for this app.

Release assets include `SHA256SUMS` for checking downloaded files. You do not need Go, Bun or a separate archive engine to use the app.

### Make ZipGallery the default archive app

In Finder, select an archive and press `⌘I` to open **Get Info**. Under **Open with**, choose ZipGallery, then click **Change All**. Repeat for each file format you want to associate.

The app declares support for ZIP, CBZ, 7z, RAR, tar, gz, bz2, xz and tgz associations. Installing it does not automatically change every user's default applications.

## Quick start

### Read an image collection or comic

1. Click **Open archive…** or press `⌘O` and choose a ZIP / CBZ file. You can also drop it into the window.
2. Open a folder, or choose **All images** to browse across folders.
3. Click a thumbnail to open the viewer. In **Fit to window** mode, scroll or use the arrow keys to turn pages.
4. Press `Esc` to return to the grid. Next time, open the archive from **Recent files** and click **Resume** to return to your saved position.

Unencrypted ZIP / CBZ archives are previewed directly. Other unencrypted formats and archives without previewable images open in the file list. Encrypted archives require a valid password before opening; supported images are previewed from a private temporary extraction. Temporary preview files are removed when switching archives or quitting, and encrypted thumbnails are not saved to the disk cache. Passwords stay in memory for the current app session and are invalidated if the archive changes.

### Extract or create an archive

**Extract:** open an archive (unlock it first if encrypted) → click **Extract** → click **Start** → choose a new output folder name. Unencrypted archives show no password field; encrypted archives reuse the password verified when opening. You can monitor progress or cancel while the job runs.

**Create:** click **Create archive** → choose multiple files from the same directory, or one folder → select ZIP / 7z / tar.gz → optionally set a password → click **Start** and choose a new output filename. Passwords are not available for tar.gz.

Passwords are not saved in history. Extraction rejects unsafe paths and links. If the destination already exists, choose a new name.

### Use an SMB share

First connect to the SMB share in Finder using **Go → Connect to Server** (`⌘K`). Once mounted, click **Mounted shares** in ZipGallery, or select the shared directory in an open or save dialog.

macOS manages server authentication. ZipGallery does not currently provide in-app SMB login, automatic reconnection or network timeout settings. If a share goes offline, reconnect it in Finder first.

### Repair garbled filenames

Open a ZIP / CBZ archive, click **Repair filename encoding…**, choose GB18030 / GBK, Shift-JIS or CP437, inspect the preview, and save a UTF-8 copy.

The original archive is preserved. This repairs filename encoding, not damaged compressed data, and cannot guarantee recovery of filename information that has already been lost. Check the preview before saving.

### Keyboard shortcuts

- `⌘O`: open an archive.
- `←` / `↑` / `PageUp`: previous image; `→` / `↓` / `PageDown`: next image.
- `0`: fit to window; `1`: actual size; `+` / `−`: zoom.
- `Esc`: close the viewer and return to the grid.
- `Option + ←` / `Option + →`: previous / next archive opened in the current session.

## Limitations and FAQ

**Why does transparency look different from the original?** The preview pipeline currently outputs JPEG, so PNG / WebP transparency and exact lossless pixels are not preserved in previews. This does not modify the original archive or extracted files. Animation playback and HEIC / RAW previews are not supported yet.

**Can I open very large images?** Each image is limited to 96 MiB of decompressed input and 24 million pixels. Tiled rendering of larger images is not available. An image that exceeds the limit displays an error; other images remain browsable.

**How do I update?** Quit ZipGallery, then replace the old app in Applications with the new version. Recent-file records and caches live in your user data directories; replacing the app normally leaves them intact. There is no in-app automatic update interface yet.

**How do I report a problem?** Open an [issue](https://github.com/DuckFeather10086/ZipGallery/issues) with the app version, macOS version, archive format, whether encryption or SMB is involved, and steps to reproduce. Remove personal content before sharing samples; a small synthetic reproduction is preferred.

## Build from source

Install Go, Bun and Xcode Command Line Tools on macOS. The currently tested tool versions are Go 1.27.1 and Bun 1.4.2.

```sh
git clone https://github.com/DuckFeather10086/ZipGallery.git
cd ZipGallery
bun install --frozen-lockfile
go mod download
bun run build
```

The app and DMG are written to `build/darwin-arm64/`. See the [development guide (中文)](docs/DEVELOPMENT.md) for development, tests, architecture and screenshot sample generation, and [VALIDATION.md](docs/VALIDATION.md) for validation records.
